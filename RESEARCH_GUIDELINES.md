# Research State Update Policy

RESEARCH_STATE.md represents the accepted current research state.

Do not update it merely because:

- a code change was made,
- an experiment was launched,
- a single qualitative example looked promising,
- or a speculative interpretation was proposed.

Update RESEARCH_STATE.md only when:

1. the user explicitly requests a state update, or

2. a completed experiment provides meaningful evidence that changes:

   - an active hypothesis,
   - a supported finding,
   - a rejected hypothesis,
   - a known failure mode,
   - the current method,
   - or the priority of next experiments.

Before making a substantial state change, summarize:

[PROPOSED STATE CHANGE]

Previous state:
...

New evidence:
...

Proposed update:
...

Confidence:
...

Do not silently promote a tentative finding into a supported finding.
